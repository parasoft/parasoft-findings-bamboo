# Parasoft Findings for Bamboo

Parasoft Findings enables you to visualize test results generated by Parasoft products in Bamboo. It includes a task that converts Parasoft's XML reports into graphs so you can conveniently view the test details.

For documentation please visit the link [Parasoft Findings for Bamboo](https://www1.parasoft.com/doc/link?product=findingsBamboo010) 

## SOAtest transformation regression tests

Run from the repository root with JDK 17 and Maven:

```sh
mvn test-compile org.apache.maven.plugins:maven-surefire-plugin:3.1.0:test -Dtest=SoatestXunitTransformationTest,ReportCollectorTest
```

The tests transform the six local reports in `src/test/resources/reports/soatest-regression` using the plugin's actual stylesheet and the existing Saxon dependency. They check testcase and failure counts, case association, message fallbacks, and diagnostic details without a SOAtest installation, license, or running service.

The reports originate from the sanitized canonical fixtures in Parasoft's XSLTTemplates project. `SOAtest_functional_execution_violations.xml` and `association_edges.xml` are synthetic regression inputs; `soatest_visual_difference.xml` and the three `soatest_parabank_change_impact_*.xml` files are sanitized report captures. All six fixtures are copied locally so these tests have no dependency on another checkout.
